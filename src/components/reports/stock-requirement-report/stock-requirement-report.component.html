How the quantities are calculated
  • Current Stock — inventory stock as recorded (Goods Inward in, Pick List scans and Packing completion out). Can be negative when a barcode was picked with no stock on record.
  • Pending SO Qty — ordered qty minus qty dispatched on Delivery Challans, per Sales Order line. A DC balance closed back to stock is not dispatched. Fully dispatched lines are excluded; extra qty dispatched on one line never offsets another line. Same figure as the other pending-order reports.
  • Reserved (Picked, Not Dispatched) — picked for a pending order but not yet on a DC. Picking already deducted these pieces from Current Stock, so they count toward the order, not against stock.
  • Required from Stock = Pending − Reserved. Available Stock = Current Stock (0 if negative).
  • Additional Required = Required from Stock − Available (if positive). Excess = Available − Required from Stock (if positive) — stock free for new orders.
  • Stock is allocated to pending orders oldest order date first; the Sales Order breakdown shows which orders are covered and which are short.
  • Status: Zero Stock when nothing is available, Insufficient when available stock does not cover the requirement, otherwise Sufficient. At Style & Color level, shortages and excess are summed per size — surplus in one size never covers another.
  • Stock Value = Current Stock × WSP, Pending SO Value = Pending SO Qty × WSP, per item (size). WSP is the Design Master rate for the size, else the rate on the inventory record. Style & Color and Product / Group values are the sums of their sizes.
  • There is a single stock location in the system (no warehouse field on inventory), so the report is not split by warehouse.
